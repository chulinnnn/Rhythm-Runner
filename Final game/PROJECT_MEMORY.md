# Final game Project Memory

This file is the required working memory for the `Final game` Unity project.

## Required Workflow
- Read this file before making any change inside this project.
- After any code, scene, asset, or project-setting change, append a short entry under `Change Log`.
- Do not restore anything from `../BunnyLegacyArchive` unless the user explicitly asks for it.

## Current Scene Map
- `Start` is the menu scene.
- `Start -> OceanRhythm` for the Little Rhythm Ocean mode.
- `Start -> VerticalRunner` for the vertical rhythm runner mode. `VerticalRunner.unity` was copied from `Tutorial.unity`; Tutorial-authored sprites, UI image slots, templates, and background Inspector settings are the canonical vertical visuals.
- `Start -> AdvancedRunner` for the advanced runner mode. Advanced tutorial and game flow run inside the same scene.

## Legacy Bunny Archive
- Target archive path: `../BunnyLegacyArchive`.
- Legacy bunny runner content is treated as archived, not deleted.
- Archived content must stay outside `Assets` so Unity does not import, compile, or run it.

## UI Hierarchy Rule
- Every active scene keeps its own editable UI hierarchy in the scene.
- Runtime scripts may update dynamic text, image fill amounts, active states, beat highlights, and button listeners.
- Runtime scripts must not create the main UI layout or overwrite RectTransform sizing, anchors, fonts, colors, background images, panel styles, or button styles.

## Vertical Runner Rules
- `VerticalRunner.unity` tutorial-authored sprites, image slots, templates, and `vertical` background settings are the canonical vertical visuals. Do not overwrite them from old `Game.unity`.
- Visible vertical text should stay short for children and stay in the monkey climbing, banana, and parrot story. Avoid visible color-teaching words and adult labels such as `Goal`, `Success`, and `Failure`.
- Rhythm rule: Space jumps upward every 2 beats on zero modulo beat slots; bananas are grabbed with `Down/S` only on the non-zero modulo beat slots; parrot dodges require holding `Space` plus `Left/Right` on the non-zero modulo beat slots.
- Banana and parrot events must not be generated on the same between-jump beat.
- Vertical runs count misses instead of using heart-based death, and show score, bananas, combo, and misses. Game mode saves `LeaderboardMode.Easy`; tutorial mode does not save leaderboard scores.
- After each vertical Start button, music starts immediately and input unlocks after an 8-beat countdown.
- Feedback should be visual and obvious: miss/damage flash, score/HUD pulse, jump/banana/parrot feedback, and a bottom beat lane that highlights Space jump beats only.
- `VerticalScrollingBackground` should scale tiles to cover the camera height and align the first visible tile around the camera center so the opening view does not show the background seam in the middle.
