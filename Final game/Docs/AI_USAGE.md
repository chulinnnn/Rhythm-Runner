# AI Usage — Rhythm Playground

**Tools:** Cursor AI, ChatGPT  
**Project:** Rhythm Playground (`Final game`)

AI was used as a support tool only. All outputs below were reviewed and verified by the author in Unity before inclusion in the final build.

## What AI was used for

1. **Code assistance** — Partial logic, hierarchy bakers, bug-fix drafts, and refactor suggestions. Core gameplay rules and final code paths were checked by the author in Play mode.
2. **Generated assets** — Some UI and background visuals via ChatGPT; filtered, edited, and placed manually in Unity Hierarchy.
3. **Comment translation** — English XML / code comments on existing scripts; wording checked against actual behaviour.
4. **Test scripts** — Draft EditMode scene contract tests (e.g. Build Settings, Hierarchy paths, prompt raycasts); run and maintained by the author.
5. **Q&A support** — Answers when blocked on Unity, UI, audio timing, or scene issues; adoption always at the author’s discretion.

## What AI did not decide

Four-mode design, beat rules, difficulty, playtest-driven changes, asset licensing, and final build approval.
