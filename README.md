## Quick start

```bash
git clone https://github.com/chulinnnn/Rhythm-Runner.git
cd Rhythm-Runner
```

1. **Capstone:** Unity Hub → Open → `Final game/` → Play `Start.unity`
2. **In-class project:** Unity Hub → Open → `2Dinclass/`

Do not commit `Library/`, `Temp/`, or `.exe` files under Assets.
